## Changes {#changes}

- Updated dependencies to address reported vulnerabilities.
- Added PostgreSQL 16 collectors and PostgreSQL 15 compatibility fixes ([#35](https://github.com/pgsty/pg_exporter/pull/35), [@japinli](https://github.com/japinli)).
- Added ARM64 packages.
- Removed the fixed `monitor` schema from `pg_query` queries. `pg_stat_statements` must be visible through `search_path`, such as when installed in `public`.
- Accepted `.yml` as well as `.yaml` in configuration directories ([#34](https://github.com/pgsty/pg_exporter/pull/34), [@japinli](https://github.com/japinli)).
- Changed PgBouncer version-parsing messages from info to debug level.
- Added the missing `relid` column to `pg_table_10_12`.
