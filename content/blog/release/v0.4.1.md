## Changes

- Excluded Citus and TimescaleDB internal schemas from object monitoring.
- Removed duplicate `pg_statio` rows.
- Added PgBouncer 1.16 support.
- Fixed overlapping `pg_repl` collector branches on PostgreSQL 12.
- Added `-T`, `--connect-timeout`, and `PG_EXPORTER_CONNECT_TIMEOUT` to control connection timeouts, including for remote targets.
- Renamed the RPM configuration file from `pg_exporter.yaml` to `pg_exporter.yml`.
