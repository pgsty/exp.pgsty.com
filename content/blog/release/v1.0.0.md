## Changes

Added PostgreSQL 18 collector branches:

| Branch | Changes |
| --- | --- |
| `pg_wal_18` | Removed `write`, `sync`, `write_time`, and `sync_time`; PostgreSQL moved these statistics to `pg_stat_io` |
| `pg_checkpointer_18` | Added `num_done` and `slru_written` |
| `pg_db_18` | Added `parallel_workers_to_launch` and `parallel_workers_launched` |
| `pg_table_18` | Added `table_parallel_workers_to_launch` and `table_parallel_workers_launched` |
| `pg_io_18` | Added WAL statistics and `read_bytes`, `write_bytes`, and `extend_bytes`; removed `op_bytes` |
| `pg_vacuuming_18` | Added `delay_time` |
