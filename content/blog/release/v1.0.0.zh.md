## 变更 {#changes}

新增 PostgreSQL 18 采集器分支：

| 分支 | 变更 |
| --- | --- |
| `pg_wal_18` | 移除 `write`、`sync`、`write_time` 和 `sync_time`；PostgreSQL 已将这些统计移至 `pg_stat_io` |
| `pg_checkpointer_18` | 新增 `num_done` 和 `slru_written` |
| `pg_db_18` | 新增 `parallel_workers_to_launch` 和 `parallel_workers_launched` |
| `pg_table_18` | 新增 `table_parallel_workers_to_launch` 和 `table_parallel_workers_launched` |
| `pg_io_18` | 新增 WAL 统计与 `read_bytes`、`write_bytes`、`extend_bytes`；移除 `op_bytes` |
| `pg_vacuuming_18` | 新增 `delay_time` |
