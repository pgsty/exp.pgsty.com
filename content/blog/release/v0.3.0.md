## Changes

- Updated the default configuration for PostgreSQL 13 metrics, including `pg_slru`, `pg_shmem`, `pg_query13`, and `pg_backup`.
- Added HTTP endpoints for health and recovery-state checks.
- Added a startup HTTP server that reports `pg_up 0` until initialization finishes.
- Added `sslmode=disable` when the connection URL omits `sslmode`.
- Fixed bugs and spelling errors.
