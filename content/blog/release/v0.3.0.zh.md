## 变更

- 更新默认配置，支持 PostgreSQL 13 指标，包括 `pg_slru`、`pg_shmem`、`pg_query13` 和 `pg_backup`。
- 新增健康与恢复状态检查的 HTTP 端点。
- 在初始化完成前提供 HTTP 服务，并报告 `pg_up 0`。
- 连接 URL 未指定 `sslmode` 时，补充 `sslmode=disable`。
- 修复程序与拼写错误。
